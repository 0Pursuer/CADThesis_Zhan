# 后续填写与提交前检查

## 本人信息与范围

- [ ] 确认最终题目及“形变特征”定义。
- [ ] 确认学位类别、全日制/非全日制、专业名称与英文名称。
- [ ] 填写姓名、学号、导师、学院、分类号、保密状态及各日期。
- [ ] 按真实分工核对本人完成、主导协作与集成内容。

## 文献与论证

- [ ] 完成1.2各路线的真实文献阅读和引用，核查标准/格式的适用范围。
- [ ] 说明现有研究不足后，再界定本论文贡献，不使用无依据的优先性表述。
- [ ] 每个关键方法交代输入、输出、前提、过程与失败边界。
- [ ] 第三章字段表和第五章实际覆盖表分开，避免以定义替代完成。

## 实验与摘要

- [ ] 冻结配套代码、CAD版本、模板、单位、比较工具及容差。
- [ ] 准备三条同系统基线与六条跨系统路线，明确样本筛选和各统计分母。
- [ ] 补齐目标重读和当前字段检查，保证结构/参数验证确实执行。
- [ ] 分别检查曲线、平面和实体；区分未比较、比较失败与明确不一致。
- [ ] 在目标原生模型中修改尺寸及上游参考，检查再生，不以重新转换代替。
- [ ] 补入真实结果、失败分析与阶段耗时；历史记录不得直接替代本轮结果。
- [ ] 根据结果改写中英文摘要末段与第七章，并保持范围一致。

## 排版与文件

- [ ] 以学院及当届要求核对封面、学位名称、页边距、字体、标题、图表及文献。
- [ ] 隐藏或删除所有“写作提示”，完成参考文献、附录、致谢及真实成果清单。
- [ ] 恢复正式双面起章要求，在本人环境重新编译至少两轮。
- [ ] 核对三级目录、书签、页码、图表引用，确认无缺字、溢出或孤立关键词。
- [ ] 不分发字体文件；原创性声明仅在本人确认后签署。
